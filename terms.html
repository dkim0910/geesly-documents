7. Rating and Matching System

Geesly uses a 5-star rating system for matchmaking:

How It Works:

  • 5-Star Rating = Like: Indicates interest; may result in a match if reciprocated
  • 1-4 Star Rating = Pass: User moves to your "seen users" list
  • User Score: Each user accumulates a score based on ratings received, affecting profile visibility
  • Distance Filter: Only users within 300km (186 miles) are shown. Users beyond this distance will never appear in your feed
  • Location Ranking: Users without location data are shown last, after all nearby users have been rated

Matching Algorithm:

Profiles you see are determined by:

  • Your preferences (gender, age range, maximum distance, body type)
